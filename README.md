# 🤖 SAS to PySpark Agentic Converter

This project is a **multi-agent AI-powered translator** that converts **SAS code into PySpark**, using:
- ✅ Rule-based parsing and mapping logic
- 🤖 Gemini API (via `google-generativeai`)
- 📜 Session logging + history
- 🌐 Streamlit UI for side-by-side comparison and file download

---

## 📈 Features

- Agentic architecture with specialized agents:
  - `ParsingAgent`
  - `RuleBasedTranslationAgent`
  - `GeminiTranslationAgent`
  - `ValidationAgent`
  - `FeedbackAgent`
- Multi-tab UI (Convert | History)
- Downloadable PySpark output
- Modular and ready to extend for Any-to-Any code conversion
